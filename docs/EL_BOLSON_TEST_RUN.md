# Тестовый забег в Эль-Больсоне

Подготовлен 2 октября 2026. Это персональный офлайн-сценарий «Нулевой слой»
для iPhone: 30 минут, 8 интервалов, 10 сюжетных сцен, 27 подсказок тренировки.

## Маршрут

Старт и финиш — середина **Avenida Patagonia Argentina** в Эль-Больсоне,
Рио-Негро. Середина рассчитана по половине длины всей нанесённой на карту
улицы, а не по центру её ограничивающего прямоугольника.

Круг: Avenida Patagonia Argentina → Los Guindos → Cuyén → Los Guindos →
Pucará → Avenida Patagonia Argentina → старт. Расчётная длина **1,91 км**.
Все повороты соединены общими узлами OpenStreetMap; Ruta Nacional 40
не входит в маршрут. Длина по карте не является полевым измерением.

Источник: [Avenida Patagonia Argentina в OpenStreetMap](https://www.openstreetmap.org/way/143070262).
© OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
Копия исходной карты, координаты старта и геометрия хранятся только в
игнорируемой Git папке `research/r02/local/el_bolson/`.

В этой папке также есть `planned-route.gpx`: это план с элементами `<rte>`,
без записанного GPS-трека и времени. Его можно открыть в приложении,
поддерживающем импорт GPX-маршрутов.

## Запуск на Mac

Нужны Xcode, установленный iPhone Simulator, XcodeGen, ffmpeg и macOS `say`
с русскими голосами. Для Python-проверок установи `requirements-dev.txt`.

```sh
# Подготовить отсутствующие локальные материалы, проверить и открыть приложение.
make el-bolson-preview
```

Первый запуск скачивает карту OSM и синтезирует звук. Следующие запуски
используют сохранённые материалы. Команда не перезаписывает существующие
полевые заметки и не пересинтезирует готовый звук. При изменении сценария
или голосов новый файл нужно собрать явно и проверить его отпечаток:

```sh
make el-bolson-audio
make el-bolson-prepare
```

Версия macOS и голосового пакета может менять результат синтеза. Проверка
сравнивает файл и manifest с отдельным зафиксированным отпечатком маршрута
в `tools/r02_release_profiles.py`; совпадение двух произвольно изменённых
локальных файлов само по себе не принимает новый master.

Для уже выбранного симулятора можно указать точное устройство:

```sh
make el-bolson-preview SIMULATOR='platform=iOS Simulator,id=YOUR-SIMULATOR-UDID'
```

## Пробный круг в приложении

На главном экране нажми **«Попробовать маршрут»**, затем **«Начать тестовый
круг»**. Скорость 30× показывает всю миссию за минуту; 120× — за 15 секунд.
Видны положение на сохранённой схеме, текущий интервал и время до его смены.
Пауза останавливает виртуальное время; уход в фон также ставит тест на паузу.

На финише приложение показывает все посещённые точки и завершённые интервалы
и сохраняет отдельный `simulation-*.json`. В отчёте нет координат и ID
участника. Экспорт доступен через системную кнопку Share. Симуляция запускает
тот же автомат состояний с виртуальными входными данными, но не исполняет
действия записи GPS, исследовательского журнала, очереди дебрифов или approvals.

Если на Mac закончится место, отчёт может не сохраниться. Результат остаётся
на открытом экране: освободи место и повторно нажми «Сохранить результат теста»
до выхода назад. После сохранения он доступен в разделе «Пробные забеги»
на главном экране. Такое восстановление проверено на iOS 26.2 Simulator.

Виртуальный тест не проигрывает ускоренную речь. Настоящий подготовленный
master доступен отдельно в **«Прослушать дома»**. Он привязан к местам этого
маршрута, полностью сохранён на устройстве и работает без потоковой загрузки.

## Перед настоящим выходом

Карту можно открыть через **«Проверить маршрут»**. Геометрия доступна без
сети; фоновая картографическая подложка Apple Maps может требовать сеть или
предварительный кэш. Схема на главном экране и в симуляции полностью офлайн.

Дневной обход, пригодность покрытия и переходов, рельеф, публичность старта,
реальное время прихода к сюжетным точкам и работа звука с заблокированным
экраном на физическом iPhone ещё требуют проверки человеком. Автоматическая
подготовка оставляет соответствующие подтверждения выключенными.
Аудио пока следует фиксированному расписанию, а не фактическому приходу к POI.

Для установки на свой iPhone открой `ios/RunGameFounder/RunGameFounder.xcodeproj`,
выбери свою Apple Team и устройство. Сначала подготовь реальные ресурсы
через `make el-bolson-prepare`; синтетический CI bundle для выхода не подходит.
Остальные шаги полевой фиксации описаны в
[`R02_FOUNDER_IPHONE_TEST_GUIDE.md`](R02_FOUNDER_IPHONE_TEST_GUIDE.md).
